# House Preview

Interactive staircase colour preview for the house renovation.

## Current app

- Recolour the staircase banisters using curated presets or any custom colour.
- Keep the handrail as the original dark reddish timber or preview other finishes.
- Inspect the banister and handrail masks directly on the photograph.
- Export the current preview as a PNG.
- Responsive layout for desktop, iPhone and iPad.

## GitHub Pages

A GitHub Actions workflow in `.github/workflows/pages.yml` deploys the root of `main` to GitHub Pages.

## Planned next stage

Add an upload workflow so a user can submit another room photograph, use AI to identify editable objects/regions and generate masks, review or refine the masks, and then recolour each region interactively.
